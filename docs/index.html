3 steps, about 15 minutes.

  1. Install it on your laptop or phone

    Install Node.js, download Cinema 3D and run npm install. On Android, use the Termux app. The laptop guide and phone guide walk through every command.

  2. Add your movies and start it

    Drop your files in the movies folder, or point it at a USB stick. Run npm start and it shows the address to open.

  3. Open it in the car

    Connect the car to your phone’s hotspot, open the car’s browser and type the address. Pick a movie and a seat.

    Questions people ask.

    Does it need internet in the car?

    No. The car joins your phone’s hotspot and the movie goes straight from the phone to the car. Nothing is loaded from other websites, so no mobile data is used for the movie.

    Can I put my movies on the car’s USB stick?

    Not the car’s own USB port: the car’s browser can’t read it. Plug the USB stick into an Android phone with a USB-C adapter instead, and the phone serves the movies to the car.

    Has it been tested in a real Tesla?

    Not yet. It has been tested in desktop Chrome, on a laptop’s built-in graphics, and on an Android phone emulator. If you try it in your car, please share how it went using Get help.

    Which movie files work?

    MP4, MKV, WebM, MOV, M4V and OGV. Files the car’s browser can’t play, usually 4K HEVC, are marked “Needs Converting” and can be turned into a copy that plays. The original file is not changed.

    Is it really free?

    Yes. It’s open source under the ISC licence. There is no account, no subscription and nothing to buy.

    Can I watch while driving?

    No. Only watch while parked, the same as the car’s own Theater.

    Is it legal?

    Cinema 3D plays files you already have. It doesn’t download or share anything. Only play movies you have the right to watch.
